# 🛡️ SOC Learning Journal

Welcome to my Security Operations Center (SOC) Learning Journal. 

This repository serves as a living, continuously updated documentation of my journey mastering core cybersecurity defense skills. Rather than just completing tutorials, I use this space to distill complex concepts into actionable knowledge, cheat sheets, and detection logic.

## 🎯 Purpose
The goal of this journal is to demonstrate **continuous learning** and **practical application** of SOC fundamentals, including:
- **Log Analysis:** Parsing and understanding raw Windows, Linux, and Web logs.
- **SIEM Operations:** Writing and optimizing Splunk SPL and Elastic queries for threat hunting.
- **Incident Response:** Documenting triage workflows, process lineage analysis, and containment strategies.
- **Network Security:** Analyzing PCAPs and understanding protocol-level anomalies.

## 📚 How to Use This Repo
Each Markdown file in this repository represents a specific concept, tool, or workflow I have mastered. They are designed to be quick references for myself and proof of technical communication skills for hiring managers.
